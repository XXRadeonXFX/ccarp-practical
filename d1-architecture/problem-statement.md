
# Bussiness Problem
Engineers spend too much time manually reading Azure incidents descriptions, searching multiple runbooks, and deciding the correct troubleshooting steps.

# Exact  Task
Anslyze one Azure incidents and recommend  the most relevant troubleshooting runbook.

# Input
-> Incident Title
-> Incident Description
-> Azure Resource Type 
-> Error Message 

# Output 
-> Incident Category
-> Likely Cause
-> Recommended Runbook
-> Troubleshooting Steps
-> Escalation Required: Yes or No
